Why this module

Dynamic Reports Budget Columns

How it works

Selection-based activation

Budget columns appear only when you choose a budget in the report's budget_id option. Without selection, the P&L displays normally. No automatic generation or module-level defaults.

Accuracy

Type-based section reconciliation

Income and expense section budgets are derived from account types, not summed from arbitrary budget lines. This ensures section totals always reconcile exactly with actuals.

Scope

Requires budget module

Depends on eh_account_budget_pro to provide the budget records and budget line data. Cannot function standalone.

Day in the life

Manager reviews P&L with budget

Choose live budgets by default or disclose all lifecycle states, then select an identified version and daily-overlap or exact-period treatment. Report renders Actual, Budget, Actual-minus-Budget Variance, and Variance Percent. Income increases and cost reductions show favourable; overspends show adverse. Analytic budgets use weighted journal-item distributions.

Edge cases

The cases most modules quietly ignore.

In the shipped code today, each one a place where a cheaper module silently does the wrong thing.

Missing budget

Removed or inaccessible selections clear safely and return standard P&L columns.

Zero budgets

Variance remains actual minus zero; percentage stays blank because no meaningful denominator exists.

Analytic scope

Analytic budgets use one plan and weighted actuals. Mixed global and analytic lines fail closed.

Rounding

Rows and totals use selected presentation-currency precision; no fixed two-decimal assumption.

What is inside

Built to do the job, end to end.

  • models/profit_and_loss_budget.py. Computes currency-rounded Budget, Actual-minus-Budget Variance, and Variance Percent rows and totals. Analytic scopes reuse allocation-weighted report SQL.
  • models/budget.py. Supplies report-aware, company-scoped choices with explicit live/all lifecycle filtering and version identity.
  • static/src/budget_filter.*. Adds synchronized lifecycle, budget, and apportionment controls plus favourable/adverse variance colouring.
  • tests. Covers amount, percent, analytic allocation, partial periods, cache identity, company scope, UI selection, currency, hierarchy, and fail-closed dimensions.
  • __manifest__.py. Depends on Dynamic Reports and Budget Pro. LGPL-3, v19.0.1.0.7.

Honest about the edges

What this does not do, so nothing surprises you.

  • Requires eh_account_budget_pro.
  • Supports one report company, one coherent company-wide or analytic scope, and by-nature P&L.
  • Journal, partner, horizontal-company, mixed-scope, by-function, and column-axis comparisons fail closed.
  • Budget generation and forecasting remain Budget Pro responsibilities.
  • Presentation-currency values use report period-average flow translation and currency-rounding policy.
